# WebHalloWelt

Ein Visual-Studio-Projekt zur Einführung in die Entwicklung von Webanwendungen mit .NET.

## Beschreibung

Das Projekt **WebHalloWelt** dient als Einstieg in die Webentwicklung. Im Mittelpunkt stehen die grundlegende Struktur einer Webanwendung, die Darstellung von Inhalten im Browser und die ersten Schritte bei der Entwicklung webbasierter Anwendungen.

## Funktionen

- Erstellung einer einfachen Webanwendung
- Darstellung von Inhalten im Webbrowser
- Grundlagen der webbasierten Benutzeroberfläche
- Einführung in die Struktur eines Webprojekts
- Lokale Ausführung und Testen der Anwendung

## Technologien

- Microsoft Visual Studio
- .NET
- Webtechnologien

## Installation und Ausführung

1. Repository klonen:

   ```bash
   git clone https://github.com/samad-pour/WebHalloWelt.git
   ```

2. Die Datei `WebHalloWelt.sln` in Visual Studio öffnen.
3. Das Projekt erstellen.
4. Die Anwendung mit `F5` starten.
5. Die Webanwendung im Browser öffnen, sofern sie nicht automatisch gestartet wird.
